# Логотипы

Логотип «Атвинта» с сайта atwinta.ru, 164×40, SVG.

- `atwinta-logo-dark.svg` — буквы #222222 (`black`), черта под «и» #FF2159 (`pink`). Для светлого фона.
- `atwinta-logo-light.svg` — буквы белые, черта #FF2159. Для тёмного фона, героя и фото.

Свободное поле — не меньше высоты черты над «и» со всех сторон. Не ставьте на `pink` и `yellow`.
