# Иконки

Интерфейсные иконки Material Symbols (Apache 2.0) — те, что сайт подключает через Iconify. 24×24, одна заливка #222222 (`black`). Чтобы получить другой цвет, перекрасьте `fill` в копии файла: через `<img>` цвет не наследуется.

- `arrow-outward` — переход к кейсам и пунктам меню услуг
- `arrow-forward`, `arrow-back` — карусели и «далее»
- `chevron-left`, `chevron-right` — пагинация
- `keyboard-arrow-down` — пункты меню с подменю
- `close` — закрыть cookie-плашку и модальные окна (на сайте — `pink`)
- `add`, `remove` — раскрытие FAQ и счётчики
- `search` — поиск в блоге
- `play-arrow` — запуск видео
- `note-add-outline` — «Приложить файл» в форме

Фирменные пиктограммы 30×30 в цвете #FF2159 (`pink`):

- `service-arrow` — стрелка строки услуги на мобильном, обводка 2px, square cap
- `service-dot` — точка по центру строки услуги
