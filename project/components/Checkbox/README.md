# Checkbox

Квадратный чекбокс 22px с рамкой 2px и розовой галочкой; используется для согласий в форме заявки.

## Состояния
- Покой: рамка `gray`, скругление `radius-xs`.
- Наведение и отмечен: рамка `pink`, галочка `pink`.
- Внимание (`is-attention`): если пытаются отправить форму без согласия — обводка 3px `pink` с отступом 6px и `radius-sm`, подложка розовая 12%, тень `attention-ring`, текст становится `pink` medium, элемент вздрагивает (0.5s, отключается при reduced motion).

## Что передаёт потребитель
Текст согласия (может содержать `at-textlink`), состояние `checked`, обработчик изменения.

## Правила
- Текст — `text-p-x` (15/20 light), цвет `ink-secondary`, зазор до бокса 15px.
- Не красьте фон отмеченного бокса: отметка — только галочкой и рамкой.
