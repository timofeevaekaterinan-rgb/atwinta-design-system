# Link

Ссылка навигации, которая при наведении «заливается» слева направо акцентным цветом, и подчёркнутая текстовая ссылка.

## Варианты
- `at-link at-link--dark` — на светлом фоне: текст `black`, заливка `pink` (токен `link-hover`).
- `at-link at-link--light` — на тёмном: текст `white`, заливка `yellow`.
- `is-current` — текущий раздел, залит целиком.
- `at-link__line` — необязательная линия 2px под ссылкой с прозрачностью 0.3, исчезает при наведении.
- `at-textlink` — ссылка внутри абзаца: подчёркивание `pink` 50%, отступ 6px, на ховере текст `pink`.

## Что передаёт потребитель
Текст ссылки (одно слово для меню), `href`, признак текущего раздела. Для пунктов с подменю — иконка `keyboard-arrow-down` после текста.

## Правила
- Стиль текста меню — `ui-link` (18/28 light), на узких экранах 16px.
- Заливка — через `background-clip: text` с градиентом 50/50, переход 0.3s linear.
- Телефон и почта в шапке оформляются как `at-textlink`.
