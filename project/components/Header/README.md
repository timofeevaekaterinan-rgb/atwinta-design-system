# Header

Закреплённая шапка высотой 90px: логотип, меню, телефон, жёлтая CTA и бургер; фон — белый 60% с размытием.

## Структура
- Логотип 164×40: `atwinta-logo-dark` на светлом, `atwinta-logo-light` над тёмным героем.
- Меню (с 1440px): `at-link` с `ui-link`, у «Услуги» и «Решения» — стрелка `keyboard-arrow-down` и выпадающая панель с вкладками.
- Справа: телефон и почта как `at-textlink` (15/20), кнопка `at-btn--yellow` «Обсудить проект», бургер 40×40 из трёх линий 2px.
- Фон `header-bg` + `backdrop-filter: header-blur`. Над тёмным героем шапка прозрачная, ссылки `at-link--light`.

## Что передаёт потребитель
Пункты меню, телефон, почту, обработчик открытия бургер-меню, признак тёмного героя.

## Правила
- Контент под шапкой отступает на `header-mb` (80px, на мобильном 40px).
- В шапке одна цветная кнопка — жёлтая.
