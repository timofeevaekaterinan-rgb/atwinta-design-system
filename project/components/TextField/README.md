# TextField

Поле ввода без рамки: только нижняя линия 2px и подпись, которая при фокусе или заполнении поднимается над полем.

## Состояния
- Покой: линия `line`, подпись `ink-secondary` 20/30 light внутри поля.
- Наведение и фокус: линия `pink`.
- Заполнено: подпись уменьшается до 15/20 и уходит наверх, цвет `ink-muted`.
- Ошибка (`is-error`): линия `error`, под полем текст ошибки `text-p-x` цвета `error`.

## Что передаёт потребитель
`id`, текст подписи, признак обязательности (звёздочка `<b>*</b>` окрашена в `pink`), значение и текст ошибки. Для textarea («Краткое описание проекта») — тот же класс на `<textarea>`.

## Правила
- Текст в поле — `text-h-x` (20/30 light), на мобильном 15/20.
- Поле с иконкой слева получает `padding-left: 35px`, иконка `gray`, при фокусе — `pink`.
- Ошибка всегда словами, не только красной линией.
- Линия `light-gray` декоративная (1.41:1 к белому) — поле различимо по подписи; так на сайте.
