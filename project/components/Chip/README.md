# Chip

Чип-капсула с рамкой 2px: подпись секции («Партнеры», «Отзывы»), тег проекта или фильтр услуг в форме.

## Варианты
- Базовый `at-chip`: рамка `line`, текст `ink-secondary`, 40px высотой, `ui-chip` (18/26). На мобильном — 32px и 14/20.
- `is-active` — заливка и рамка `yellow`, текст `extra-dark-gray`.
- `at-chip--filter` — для выбора в форме: паддинг 6px 20px, текст `ui-chip-filter` (16/24 light), при наведении заливается `yellow`.
- `at-chip--pink`, `at-chip--yellow` — цветные метки.
- `at-chip--inverse` — на тёмном фоне: белый текст, рамка #555555. `at-chip--thin` — рамка 1px.
- Размеры `--xs` (10px, ВЕРХНИЙ РЕГИСТР), `--sm` (11px), `--md` (12px medium, 40px), `--lg` (12px medium, 44px).

## Что передаёт потребитель
Короткий текст в одно-два слова, состояние выбора (`is-active`). Для фильтров — обработчик клика на всём чипе.

## Правила
- Скругление `radius-chip`; переход всех свойств 0.3s linear.
- Не ставьте иконки внутрь чипа: на сайте чипы только текстовые.
- Выбранный фильтр отличается заливкой, а не только цветом рамки.
