# ProjectCard

Квадратная карточка кейса: фото или видео на всю площадь, сверху счётчики наград, снизу название проекта.

## Структура
- Карточка `aspect-ratio: 1`, паддинг 30px (мобильный) / 40px (720+) / 60px (1280+).
- `at-card__media` — изображение или видео на весь блок; при наведении увеличивается до 1.2 (0.3s).
- `at-card__awards` — иконки наград 60px (40px на мобильном) с числом справа, 26/32. На ховере иконки выезжают сверху по очереди, лента наград прокручивается.
- `at-card__title` — `text-p-s` с весом 500 (26/32 на 1280).
- Скин `at-card--black-skin` — белый текст поверх тёмного или насыщенного фото; `at-card--white-skin` — `black` на светлом.

## Сетка
`at-cards`: 1 колонка → 2 (720+) → 3 (1280+), зазор 1px — линии между карточками дают фон страницы.

## Что передаёт потребитель
Фото/видео кейса, название в одну фразу с результатом («8000 учеников ежедневно»), список наград с количеством, ссылку. В превью вместо фото — фирменные заливки: изображения кейсов принадлежат клиентам и в систему не копируются.
