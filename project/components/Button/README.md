# Button

Кнопка-капсула с «перекатом» цвета: при наведении снизу въезжает слой второго фирменного цвета.

## Варианты
- `at-btn--pink` — основное действие формы («Отправить», «Принять»). Фон `pink`, текст `white`; на ховере — фон `yellow`, текст `extra-dark-gray`.
- `at-btn--yellow` — главная CTA шапки «Обсудить проект». Фон `yellow`, текст `extra-dark-gray`; на ховере — `pink` и белый текст.
- `at-btn--gray` — второстепенное действие. Фон `extra-light-gray`, на ховере текст становится `pink`.

## Размеры
- По умолчанию 60px высотой, паддинг 15px 30px (от 1280px).
- `at-btn--sm` — 50px, мобильная версия.
- `at-btn--md` — 40px, паддинг 0 20px (кнопка в cookie-плашке).

## Что передаёт потребитель
Элемент `<a>` или `<button>` с классами `at-btn at-btn--<цвет>` и коротким текстом-глаголом. Текст — `text-p-x` (15/20, light), иконок внутри нет.

## Правила
- Скругление всегда `radius-pill`, без рамок и теней.
- На странице одна розовая или одна жёлтая кнопка в зоне видимости: жёлтая живёт в шапке, розовая — в формах.
- В шапке у жёлтой кнопки при наведении текст сменяется бегущей строкой (marquee 5s) и кнопка слегка пружинит — в превью не воспроизводится.
- Белый на `pink` даёт 3.74:1: для мелкого текста ниже AA. Так на сайте; если нужна доступность, делайте текст 19px+ bold или используйте `pink-dark`.
- Фокус: `outline 3px focus-ring`, отступ 6px.
