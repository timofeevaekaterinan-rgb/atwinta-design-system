# ServiceLine

Строка списка услуг во всю ширину: название слева, розовая точка по центру, описание справа, линия снизу.

## Структура
- `at-service__title` — 5 колонок из 12, `text-h-m` с весом 600, цвет `ink-secondary`. На мобильном рядом с названием — стрелка `service-arrow` 30px.
- `at-service__dot` — круг `pink` 20px строго по центру строки (с 1000px).
- `at-service__desc` — колонки 8–12, `text-h-x`, цвет `ink`.
- Нижняя граница 2px `line`, вертикальный паддинг 30px (мобильный) / 40px.

## Наведение
Граница исчезает, из середины строки по высоте вырастает заливка `surface-alt` (0.35s ease-out). На сайте в центре ещё появляется видео-превью — его потребитель передаёт сам.

## Что передаёт потребитель
Название, описание в одно предложение, ссылку на страницу услуги, при желании видео для наведения.
