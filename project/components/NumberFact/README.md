# NumberFact

Крупная цифра шрифтом Stem с фирменным хроматическим сдвигом, единица справа и описание под ней.

## Структура
- `at-fact__value` — число: `text-h-xxl`, шрифт `display`, вес 700, межстрочный 1, `text-shadow` = токен `chromatic` (жёлтый −3px, розовый 50% +3px).
- `at-fact__unit` — единица («сотрудников», «лет», «рост»): 26/32 regular, `ink`.
- `at-fact__desc` — пояснение: `text-p-special` (22/30 light), `ink-secondary`.
- `at-fact--m` — уменьшенный размер для сетки 2×2.

## Что передаёт потребитель
Число как строку (с «+», «×» если нужно), единицу, описание в одно-два предложения.

## Правила
- Отступ от цифры до описания: 10px на мобильном, 20px от 720px, 30px от 1440px.
- Хроматический сдвиг только на цифрах фактов, не на заголовках.
- Числа — реальные: «15 лет», «100 сотрудников», «6+ лет», «400+ проектов», «×2 рост».
